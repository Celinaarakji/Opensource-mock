# Security Policy

## Reporting a vulnerability

**Please do not report security problems in public issues, pull requests or
discussions.** A public report tells attackers about the problem before it is
fixed.

Instead, report it privately:

1. Go to the **Security** tab of this repository and click
   **Report a vulnerability** (GitHub private vulnerability reporting), or
2. Message the maintainers privately in the club chat.

Please include:

- What the problem is and where it is (file and function if you know)
- Steps to reproduce it, such as an example request
- What an attacker could do with it
- A suggested fix, if you have one

We'll reply within a few days, work on a fix with you, and credit you when the
fix is published (unless you'd rather stay anonymous).

## Scope

This is a teaching project and is not meant to be deployed. We still treat
security reports seriously, because practising the process is the point.
